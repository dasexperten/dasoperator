### Адаптив (mobile ≤767px / ≤480px, по deSIGNER FOUNDATION/mobile-first.md)
- [x] `das-design-tokens.css`: responsive-слой `.emailer-dark` — full-bleed канва на мобиле (`.ed-screen` гасит 16px рамку main), fluid-заголовки `ed-h1/ed-h2` (clamp), грид `ed-grid` (auto-fit на десктопе, жёсткие 2 колонки ≤480px — карточный masonry как в мокапе), tap-targets ≥44px (WCAG 2.5.5) на табах/тоглах/кнопках/чипах, `touch-action: manipulation` на всём интерактивном, `:focus-visible` gold.
- [x] Починены конфликты с глобальными mobile-правилами `globals.css` внутри модуля: правило «`.flex.gap-N.items-center` → grid 2 колонки» (фильтр-ряды светлых страниц) ломало тулбар, хронологию и карточки заказов — возвращён flex скоуп-оверрайдом; правило «`.flex.justify-between` → wrap» выталкивало текст из flex-col карточек — nowrap внутри модуля; карточки получили `overflow: hidden`.

- [x] Заказы: карточка — строка на десктопе, стек на мобиле (`ed-order-card`/`ed-order-actions`), действия не давят контент.
- [x] Экран письма: fluid-заголовок, iframe тела 55vh (min 320px), тач-таргеты формы ответа.
