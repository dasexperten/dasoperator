# E-commerce UI Kit

Product detail (PDP) + slide-out cart drawer.

- Gallery (thumbs + main)
- Product info (options, subscription, qty, claims, ingredients accordion)
- How-it-works (3 steps)
- Reviews (3 columns)
- Cart drawer (slide-in from right, overlay, cart item rows, totals, checkout CTA)

Click **Warenkorb · 2** or **In den Warenkorb** to open the cart.
