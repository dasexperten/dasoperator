# Emailer Dark UI v3 — дизайн-спека (утверждена владельцем 2026-07-11)

Источник: сессия DAS ARCHITEKTOR 2026-07-11. План внедрения: `docs/plans/plan-emailer-dark-ui.md`.
Все 7 мокапов утверждены владельцем. Референс — карточный мобильный inbox
(masonry, имя крупно), адаптированный под ERP-триаж и фирменные цвета.

## UI HARD RULE
Никакой служебной/технической информации в интерфейсе: имена бакетов,
trigger-метки, названия таблиц, источники данных НЕ отображаются ни в футерах,
ни в подписях. Интерфейс говорит языком бизнеса (заказы, заявки, письма).

## Утверждённые экраны (7)
1. **Дашборд v4** — переключатель Люди/Система (по origin) со счётчиками;
   заголовок «У вас N непрочитанных» (Archivo 900, 34px); подзаголовок
   «Люди · все ящики» #C9C1B0; поиск; табы Сегодня/Вчера/Неделя/Все;
   грид auto-fit minmax(170px,1fr): gold hero card «ЖДУТ ОТВЕТА» (row-span 2,
   count + имена контрагентов 48+ ч), карточки корреспондентов (имя крупно
   в 2 строки, направление цветом + ящик, последняя тема), карточка
   ЗАКАЗЫ·ФОРМЫ (gold-цифра, за 24 ч), приглушённая карточка СИСТЕМА.
   Max 11 карточек + «ещё N →». Внизу переключатель «списком» (старый вид).
2. **Экран письма** — назад/ящик; имя корреспондента Archivo 900 28px;
   направление+время; тема + размер треда; блок «ЧТО ОНИ ХОТЯТ» (выжимка v2:
   3–4 строки — суть, что просят, дедлайн, температура сделки; скелетон при
   генерации); чипы вложений; тело письма #221D22 (оригинал + «показать
   перевод» — этап 3); мини-хронология треда одной строкой на письмо;
   действия: Ответить (gold) → существующая reply-форма.
3. **Черновик ответа** (этап 3, дизайн зафиксирован) — шапка АI-ЧЕРНОВИК ·
   НЕ ОТПРАВЛЕНО; От/Кому/Тема; тело с gold-плашками непроверяемых полей
   (цена — только из pricer, даты — из расчёта); строка тона (personizer);
   чипы перегенерации (Короче/Формальнее/Дожать); Править + Отправить (gold);
   авто-send выключен, отправка только после явного ОК.
4. **CRM-лента контрагента** — шапка: имя Archivo 900, контакт+адреса, бейдж
   ЖДЁТ ОТВЕТА (gold); 4 метрики (писем, тредов, их темп ответа, последний
   контакт); фильтр-чипы по ящикам с количеством; вертикальная хронология
   с цветными точками (входящее green / отправлено red / система gray,
   системные приглушены); «показать ещё N →»; ссылка на карточку партнёра.
5. **Экран Заказы** — заголовок «Заказы N» + сумма подтверждённых (gold);
   фильтры Все/Заказы/Формы/Необработанные; карточки: заказ (борт gold,
   номер+источник, состав, сумма gold, статус) / заявка с формы (борт green,
   бейдж НОВАЯ, контакт, интерес); действия: Открыть заказ,
   Письмо-подтверждение, Создать партнёра (prefill email), Ответить.
6. **Вкладка Система** — «N системных за сутки» (#B4B2A9) + «всё штатно ·
   M требует взгляда»; аномалии наверху (борт #E5202C, действие Разобраться);
   группы по типам со счётчиками (подтверждения заказов, автоответы форм,
   уведомления Experten Club, служебные); «Отметить всё прочитанным».
7. **Сетка v3 (исходная)** — суперсет вошёл в дашборд v4.
