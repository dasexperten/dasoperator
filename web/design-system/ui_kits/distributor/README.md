# Distributor / B2B Portal UI Kit

Portal dashboard for Das Experten distributors (Tier A partner view).

- Dark sidebar (schwarz) with nav + avatar
- Top bar (search, language, notification)
- KPI cards (4, one inverted in brand-schwarz with gold numeral)
- Recent orders table
- Activity feed
- Catalog quick-access grid (wholesale pricing + MOQ)

The sidebar mirrors the same schwarz/rot/gold hierarchy used across the brand.
